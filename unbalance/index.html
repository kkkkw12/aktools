两种「源」是不同的点（origin = source.mapPosition + dirOffset）：
· 效果源（菱形）= 施加拉力的干员位置 —— 拉力用它判急停判据 B（急停半径 0.6708）；推力用它判溅射降级；
· 力起点 / 力源（方框）= 拉拽原点 origin —— 力的方向参照（拉力指向它、推力「由力源计算」时推离它），也是拉力衰减分子 d 的参照；★ 拉力另用它判急停判据 A（到点容差 ≤ 0.05）（填拉力时请让它 = 拉拽终点）
箭头 = 各事件的力方向（带 #n 编号，对应下方事件序列）；选中行的箭头加粗。

③失衡事件序列 — 每行一个施力事件；同一序列可含多个力，各自按自身管道择帧生效

「命中帧」之后第几帧才有位移 —— 由类型决定（三者管道不同，同一帧可并存）：
· 弹道推力 = 命中帧的 OnTick 之后施冲量 ⇒ 同帧位移
· 非弹道推力 = 命中帧的物理步之后施冲量 ⇒ 次帧位移，且该帧先经一次线性摩擦
· 拉力 = 命中帧+1 帧的协程段 BeginPull（只写力累加器）⇒ 命中帧+2 才积分成速度
时长(帧) 仅拉力有效（0 = 不限）：到点时 TryEarlyStopPull 清速度 —— ★ 只有序列里只剩它一个在册拉源才会清速度（多源共存时到点不清速度）。
方向模式：预设方向（8 选一） = 力方向恒为指定方向，且启用溅射降级判定 （对应 Nodes.Knockback._useSourceDirection 为真）；由力源计算 = 推力取「敌人 − 力源」（推离力源）、 拉力取「力源 − 敌人」（拉向力源，游戏行为），不做降级判定；非 8 方向的角度请用此模式。

⑤输出

「状态」列 = 本帧物理步所见的状态（非失衡帧整段跳过物理步 ⇒ 位置冻结）； 「源数」= 本帧帧首在册的拉动源数（= 游戏里 m_pullSources.Count，帧末注销的源不计入）； ⚠ = 该帧触发急停（判据 A 距拉力终点 ≤ 0.05 ∨ 判据 B 距效果源 ≤ 0.6708，表内标 A/B）⇒ TryEarlyStopPull 清零速度一次（不 EndPull ⇒ 失衡持续到拉力结束）。

判据速查

退出失衡（UnbalanceState.OnTick，物理步之前每帧一次，顺序固定）：
|v| ≤ 0.1 且 硬直窗已过（fixedPlayTime ≥ protectTime） 且 在册拉动源数 = 0 ⇒ 关箱、残差冻结。
★ 摩擦先判、源数后判 ⇒ 源非空即留（哪怕已停下）；出界 / 浮空 / 眩晕另有旁路，本工具不建模。
★ 只有拉力登记源（推 = KnockBack，只加一次 Impulse、不登记） ⇒ 推不延长失衡；被推被拉时，退出时机完全由拉源何时 EndPull 决定。
★ 硬直窗 = fixedPlayTime + 0.1s，只由 BeginPull / KnockBack 的施力帧刷新 —— StillPull 不刷。
TryEarlyStopPull 只在 m_pullSources.Count == 1 且就是本源时清速度。

通道开关：cd < 0 ⇒ 常规；0 ≤ cd < 0.09625 ⇒ TOI；cd ≥ 0.09625 ⇒ 无 TOI
常规位置轮：浅档（|sep| ≤ 3·slop）1 轮，深档 3 轮，系数 0.2
TOI 位置轮：系数 0.75，上限 20，出口 d ≤ 0.0025
vn < 0 ⇒ 推力被墙吃掉（与力度无关）；vn > 0 ⇒ 保留并叠加
⚠ 两种摩擦别混：① 线性摩擦 = OnTick 每帧减 0.1635（与接触无关）； ② 接触切向摩擦 = 速度轮里 clamp(p.t−vt, ±μ·p.n)（先切向后法向 8 轮， 首轮 maxF=0 ⇒ 摩擦从第二轮才起作用）
★ 拉力衰减 (当前距离 / totalDist)⁴，totalDist 在「推进 2」测一次后固定； 当前距离 > totalDist ⇒ 该帧系数取 1
★ 急停 = 两条判据（A ∨ B）：A 距拉力终点（= 力源 src）≤ 0.05（CheckDistance）；B 距效果源（= 施力者/干员中心）≤ 0.6708（地面阻挡 = √(0.49999−0.05)；空中 0.86601）⇒ TryEarlyStopPull 清零速度一次（Count==1 且本源才清）、但不 EndPull ⇒ 失衡持续到拉力结束 （两条判据都在拉拽协程主循环）
