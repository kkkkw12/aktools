个人用工具站
目录见下：
| 工具 | 路径 | 说明 |
| --- | --- | --- |
| 波次帧账分析器 | [`/wave/`](wave/) | 把一关的出怪拆成逐帧账：泳道式时间轴、逐条目账、出怪时刻表（可导出 Markdown）。内置全量关卡 |
| 失衡位移逐帧模拟器 | [`/unbalance/`](unbalance/) | 复现物理步、施力事件序列（弹道推力 / 非弹道推力 / 拉力）、实测逐帧对照（可导出 CSV） |
| 定点计时器帧长计算器 | [`/timer/`](timer/) | 把「每 N 秒触发一次」的间隔按 32 位定点数逐帧跑一遍：实际帧长、残差账、累积误差与翻帧周期（判定 / 续接 / 容差可切换） |

约定：顶层每个放着 `index.html` 的目录就是一个工具，同级只放它自己的 `.js` 载荷；
加新工具**不需要**改 `scripts/check_publish.py` 或 `.github/workflows/deploy.yml`，两边都是自动发现。
页面上的 `?` 是说明抽屉的入口，文案在 `<工具>-notes.js` 里，正文只留控件必需的字。
